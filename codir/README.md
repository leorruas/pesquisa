# CODIR | Apresentação do Portal IFMG

Apresentação para o Colégio de Dirigentes (CODIR) do IFMG, em português brasileiro. O conteúdo apresenta o diagnóstico do portal institucional, os critérios de pesquisa, a proposta de arquitetura da informação, a governança de conteúdo e a validação em curso.

A versão usa HTML, CSS e JavaScript, sem React, Next.js ou etapa de compilação. Contém 13 slides.

Arquivos:
- `index.html`: estrutura, conteúdo em português e textos de acessibilidade.
- `styles.css`: layout, tipografia, gráficos, matrizes e adaptação a telas menores.
- `script.js`: navegação por setas, barra de espaço, Page Up/Down, Home/End, botões, gestos horizontais e link direto para slides (`#slide-N`).
- `assets/`: capturas de tela disponíveis localmente.

## Acesso

Se o GitHub Pages estiver publicado a partir da raiz da branch `main`, abra `https://leorruas.github.io/pesquisa/codir/`. Também é possível abrir `index.html` diretamente em um navegador.

## Capturas de tela

Cinco imagens ainda dependem de endereços externos do portfólio pessoal para serem exibidas:
- Portal anterior
- Proposta de portal
- Guia do Estudante
- Implementação em Ouro Branco
- Guia do Portal: procedimentos

As demais duas capturas do Guia do Portal estão em `assets/`. Para independência completa, as cinco imagens externas ainda precisam ser transferidas para essa pasta e seus caminhos atualizados no HTML. A fonte DM Sans e a fonte Roboto Mono são carregadas do Google Fonts, com fontes alternativas locais.

## Cuidados na apresentação

O conteúdo preserva os indicadores, os períodos de coleta, os limites das evidências e a situação de validação descritos no material original. A tradução e a adaptação para o CODIR não constituem uma revalidação dos dados. Antes de apresentar, confirme se o andamento dos testes de Ouro Branco continua atual.
